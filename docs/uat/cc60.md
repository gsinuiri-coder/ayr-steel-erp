# UAT cc60 · límites por IP verificada (D-695, D-696)

No fuerces bloqueos en producción. Prueba el bloqueo en local o en demo.

## En producción, solo mirar

1. [ ] Usa la app normal con dos o tres personas a la vez desde la oficina: nadie ve «Demasiados intentos…».
2. [ ] (Opcional) Pídele al agente que lea el log de la API: tiene que aparecer «Límites por IP verificada del cliente».

## En local

Usa el mismo `AYR_CLIENT_IP_SECRET` en la API y en la web, y llama a la web con `X-Forwarded-For: <ip>`.

3. [ ] **Renovación de sesión por IP.**
   - Desde `198.51.100.7`, repite `POST /api/auth/refresh` más de 30 veces en un minuto: se frena con 429.
   - Desde `203.0.113.9`, sigue funcionando.
4. [ ] **Sin secreto en la web, como antes.**
   - Quita el secreto de la web y repite el paso 3.
   - Ahora todas las peticiones cuentan juntas, porque la API ve una sola IP.
